# plain-steps

Claude Code 的一个 mod。

Claude 干活时，终端里每一步都会打出完整的命令和输出：路径、参数、JSON，一屏接一屏。要知道它做得对不对，你得自己读完这些。

plain-steps 替你读完。每一步只留一行：在做什么、用了多久、成没成。出错的那一步下面留着最后几行报错，你可以直接判断要不要插手，也能顺着报错找原因。想看细节，输入 `/steps` 切回完整输出。

![plain-steps 演示](demo.gif)

## 装上

在 Claude Code 的输入框里输入：

```
/plugin install plain-steps --marketplace yishu-ziyu/plain-steps
```

问是否添加 marketplace 时输入 `y`，再选安装范围（默认用户范围，回车即可）。装好后当场生效。

想改代码再试：克隆仓库后运行 `claude --plugin-dir ./plain-steps`。

在 Claude Code v2.1.292 上测试过。

## 一行里写什么

| 显示 | 意思 |
|---|---|
| `✓` | 这一步正常结束。超过 2 秒会写上耗时，比如 `✓ 38 秒` |
| `✗ 失败` | 这一步报错退出，下面一句话说卡在哪儿；按 ctrl+o 看报错原文 |
| `超时，转到后台` | 命令超时，Claude Code 把它转到后台继续跑 |
| `在后台跑` | 这一步一开始就在后台运行 |
| `已中断` | 你中断了这一步 |

- 说明文字来自 Claude 给每条命令写的描述，所以语言跟着 Claude 走。
- `✓` 只表示命令正常结束。如果测试脚本在测试失败时仍然正常退出，这里也会是 `✓`。
- 只接管 Bash、REPL、Read、Edit、Write、Grep、Glob、Agent、SendMessage、ToolSearch、Skill 这几种工具，其他工具照原样显示。
- Code Mode（REPL）下，每段脚本一行，文字是它的说明；脚本在后台跑时显示 `进行中…`，结果送回后改成 `✓` 或 `✗ 失败`，并带上耗时；失败时下面用一句人话说卡在哪儿（另请模型读报错原文生成，比如「设置文件：不存在，读取失败」），不露报错原文；你按 Esc 或拒绝权限不算失败。没写说明的脚本，另请模型根据你最近说的话和代码补一句「为了什么」，补好前显示「正在弄清这一步要做什么…」，不露代码。脚本里跑的每条命令不另起一行，成败看脚本那一行。
- 为了让每一步都有说明，plain-steps 在系统提示里要求每次调用 REPL 和 Bash 都写一句 `description`：对象在前、冒号、再写查什么或从什么改成什么，比如「结算页优惠券：查叠加与门槛规则」；不用「为了」「正在」开头，不出现文件名和命令。
- 改了东西的步骤，跑完后这一行换成按实际执行的改动写的一句「从什么改成什么」（另请模型读实际改动生成），不再用事前的说明。实际改动和说明对不上时，句末注明「和说明不符」，整行标黄。
- 连续几段只查看、没出错的脚本合成一行，显示最新那段的说明和「查了 N 步」。改东西的、出错的脚本各占一行。看不准一段脚本会不会改东西时，按会改算。
- 不挂 `tool.call`：挂了它，新会话会关掉 Code Mode。耗时从会话记录里算。
- 按 ctrl+o 展开完整记录时，照原样显示。

## 切换

输入 `/steps`：每一步切回完整命令和输出。再输入一次：切回一行。
